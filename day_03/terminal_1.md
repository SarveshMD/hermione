3. `strace -e` introduces options to filter the output

```bash
strace -e trace=open,openat,read,write,close cat /etc/hosts
```

5. Notes

- `openat()` opened `/etc/hosts` and got the fd 3
- `cat` read the file using fd 3, wrote it to stdout fd 1
- the number after = is the return/exit status code
- `openat()` -> success returns the new FD number
- `read()` and `write()` -> success returns the byte count transferred
- `close()` -> status code 0 for success, -1 for failure
- 131072 is the maximum buffer of `cat` - 128KB
- 417 is the length of `/etc/hosts` file
- after the first `read()` that read 417 bytes, `cat` confirms it again with another read, gets the return code 0 meaning `EOF` by convention, and moves on to close the file (fd 3), stdout (fd 1) and stderr (fd 2), and exits with status 0.
